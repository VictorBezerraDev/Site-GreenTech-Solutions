# 🌱 GreenTech Solutions

Landing page institucional da **GreenTech Solutions**, uma empresa fictícia de TI verde que une tecnologia e sustentabilidade. O site apresenta os serviços da empresa, quem ela é, as novidades do blog e um formulário de contacto.

Projeto desenvolvido com **HTML5 e CSS3**, sem frameworks nem dependências de build.

## 📑 Seções do site

| Seção | Descrição |
|-------|-----------|
| **Home** | Hero com chamada principal e botão "Fale Conosco" |
| **Serviços** | Grid com três cards: Cloud Green, Otimização de Código e Consultoria ESG |
| **Sobre Nós** | Apresentação da empresa (Flexbox) com estatísticas de impacto |
| **Blog** | Grid com os últimos artigos |
| **Contacto** | Formulário com campos de nome, e-mail e mensagem |

## ✨ Destaques técnicos

- Header fixo com navegação por âncoras entre as seções
- Layouts com **CSS Grid** (serviços e blog) e **Flexbox** (sobre nós)
- Formulário com validação nativa do HTML5 (`required`, `minlength`, `type="email"`)
- HTML semântico (`header`, `section`, `article`, `nav`, `footer`)
- Idioma da página definido como `pt-BR`

## 🛠️ Tecnologias

- HTML5
- CSS3

## 🚀 Como executar

Não precisa instalar nada.

```bash
# Clone o repositório
git clone https://github.com/VictorBezerraDev/Site-GreenTech-Solutions.git

# Entre na pasta
cd Site-GreenTech-Solutions
```

Depois, abra o arquivo `GreenTech Solutions.html` no navegador (duplo clique ou botão direito → *Abrir com*).
